##  About the Project

**Hash Kill** is a blazing-fast ⚡ Ruby 3.4.6 CLI tool built for one mission:  
👉 **Dominate hashes. Crack them. Create them. Kill them.**

Whether you're a pentester 🕵️‍♂️, a security enthusiast 🛡️, or just love cracking things open 💥, Hash Kill gives you two powerful capabilities:

### 🧰 Features

1. 🔒 **Create Hashes** — Generate secure MD5 or SHA-256 hashes from any input string.
2. 💣 **Decode / Kill Hashes** — Bruteforce MD5 hashes using a password list (like `rockyou.txt`) placed in the same folder as your `script.rb`.  
   Just update this line in the code:
   ```ruby
   wordlist = File.readlines("wordlist.txt")
   ```
